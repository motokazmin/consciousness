## Анамнез практики

- Многолетний опыт практики. Конкретика — _не заполнено_.
- С возрастом часть навыков утрачена. Что именно ушло — _не заполнено_.

**Что нужно выяснить:**

- Какие практики, сколько лет, в какой традиции или самостоятельно.
- Что было доступно раньше — конкретно, по описанию состояний, а не оценочно.
- Что ушло первым, что держится дольше всего.
- Есть ли состояния, в которые вход сохранился полностью.
- Был ли перерыв, какой длины, чем закончился.

## Текущий режим

_Не заполнено._ Нужно: сон (длительность, качество, стабильность), кофеин
(количество, время), алкоголь, физнагрузка, лекарства и добавки, рабочий ритм,
основные источники нагрузки.

## Измеренные константы

Заполняется по мере измерений; каждая величина — с датой и ссылкой на `session_id`.

| Величина | Значение | Дата | Источник |
|----------|----------|------|----------|
| Резонансная частота | _не измерено_ | | протокол Лерера |
| RMSSD покоя утром (среднее ± разброс) | _не измерено_ | | серия 7–10 дней |
| Ночной HRV | _не измерено_ | | |
| ЧСС покоя | _не измерено_ | | |
| Амплитуда RSA на резонансе | _не измерено_ | | |

**Разброс важнее среднего.** Без знания собственной вариабельности от дня ко дню
любое изменение неинтерпретируемо.

## Операциональная цель

**Что значит «навык вернулся»** — _не сформулировано_. Пока не сформулировано, у
исследования нет финиша. Это блокирующий вопрос.

описание сопровождается ссылкой на сессию, где оно впервые встретилось.

## Целевые состояния для исследования

- Медитация (сидя).
- Релаксация лёжа.
- Далее — **любое состояние по выбору**; карта строится по двум осям
  (активация × собранность), см. [PLAN.md](PLAN.md).
